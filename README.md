# EventManager

## Descripción

EventManager es una aplicación web orientada a la organización y administración de eventos académicos. Su propósito es centralizar la publicación de actividades, el registro de participantes y la gestión de evidencias, certificados y control de acceso, facilitando el seguimiento de cada evento.

## Justificación

Elegí la licencia MIT porque permite que otras personas utilicen, estudien, modifiquen y distribuyan el software, incluso con fines comerciales, sin imponer que los proyectos derivados usen la misma licencia. Esto facilita que EventManager pueda servir como base para futuras mejoras o adaptaciones en entornos académicos. Quien redistribuya el software debe conservar el aviso de derechos de autor y el texto de la licencia. La licencia también limita las garantías y la responsabilidad de quienes lo ofrecen. Esta opción es adecuada porque busco permitir la reutilización del proyecto con pocas condiciones, manteniendo el reconocimiento de la autoría original.
